# 审美原理

这份参考解释本 skill 里几条规则背后的依据，并给出可以直接执行的检查。技巧 1 写方向说明、技巧 2 找点子、技巧 6 做构图检查时读。

## 一、新颖与典型：新颖预算

**依据**

- Hekkert、Snelders 与 van Wieringen（2003，*British Journal of Psychology*）用三项研究证明：典型性和新颖性对审美偏好的贡献相当，但两者互相压制。单看任何一个都和偏好没有显著相关，控制住另一个之后都高度显著。人们喜欢不损害典型性的新颖，也喜欢不牺牲新颖的典型，偏好的是两者的最优组合。这就是 Raymond Loewy 说的"最先进但可接受"（MAYA）。观者是否是设计专家，不改变两者的相对作用。
- Tuch 等人（2012，与 Google 合作）用 119 个真实网站截图发现：视觉复杂度和原型性（像不像这一类网站）在 17–50 毫秒内就影响审美评分。复杂度比原型性更早被处理，"低复杂度 + 高原型性"最受欢迎。复杂度高时，熟悉的设计也会被判为不美；不熟悉时，简单的设计也会被判为更丑。
- Hanchar（2012）在同一研究框架下发现，配色概念不典型的网站反而得到更好的第一印象。

**结论**

独特不等于每一层都陌生。把新颖集中花在少数几层，其余层保持典型：

| 层 | 默认 | 理由 |
|---|---|---|
| 首屏一眼的复杂度 | 低 | 复杂度在 17 毫秒内就被感知，最早起作用 |
| 结构与导航（导航位置、阅读顺序、可点击物的样子） | 典型 | 原型性决定"认不认得出这是什么"，破坏它的代价最大 |
| 配色 | 可以大胆 | 不典型的配色反而加分 |
| 图像、插画、材质 | 可以大胆 | 不影响用户找路 |
| 字体细节、标志性元素 | 可以大胆 | 新颖集中在一处，最容易被记住 |

**执行**：在 `.design/direction.md` 写一张"新颖预算"表，逐层写"典型"或"新颖"及理由。抽签抽到会动结构的版式原型（横向滚动长廊、物件散落桌面、竖排直书等）时，这一层就是新颖层，其余层要相应收住，尤其是导航和首屏复杂度。用户明确要实验性作品时，可以整体提高预算，但要写明。

## 二、陌生感要能看懂

**依据**

- 加工流畅性理论（Reber、Schwarz 与 Winkielman，2004）：越容易加工的东西越让人愉悦，对称、图底清晰、原型性都通过流畅性起作用。这解释了第一节里"低复杂、高原型"的偏好。
- 但人们也会喜欢难懂的东西。Graf 与 Landwehr（2015）的愉悦—兴趣模型（PIA）区分两条路：自动加工得到流畅带来的"愉悦"；当观者愿意多想时，不流畅如果在细看后被化解，就转成"兴趣"，化解不了就是"困惑"，根本没有不流畅则是"无聊"。
- Belke、Leder 与 Carbon（2015）的实验印证了这一点：有挑战性的肖像在被反复细看之后更受喜欢，而好懂的肖像不会因为多看而加分。
- Ramachandran 与 Hirstein（1999）把它叫作"知觉解谜"：意思被暗示而不是说破的画面，比一目了然的更吸引人。

**执行**：每个不寻常的元素，都要在多看一眼之后显出它和题材的关系。处方笺式导航要让人认出是处方笺，等深线背景要让人看出是地图。看了两遍还不明白在干什么的元素，要么补线索，要么删。评审 prompt 里专门问这一条。

## 三、几条知觉规律

出自 Ramachandran 与 Hirstein 的《艺术的科学》（1999）提出的八条规律，挑出对设计最直接有用的：

- **峰移（peak shift）**：夸大一个对象区别于同类的特征，比忠实描绘更能激发反应，就像漫画往往比照片更像本人。设计里：找出灵感物件最有辨识度的那一个特征，把它放大，而不是平均地模仿它的全部。时刻表的辨识度在等宽数字栏和对齐的时刻，处方笺在抬头、编号和朱红印章。
- **孤立**：一次只突出一个线索，注意力才会集中到它上面。设计里：只做一个标志性元素，其余让路。
- **图底分组与对比提取**：知觉系统会奖励"把东西从背景里分出来"。设计里：图底关系要清楚，对比集中在信息最多的地方。
- **厌恶巧合**：观者会觉得"恰好"的视角和对齐不自然，因为它们在现实中很少出现。设计里：文字恰好擦着图片边缘、两个元素恰好相切、无关元素偶然对齐，都会显得别扭。要么明确对齐，要么明确拉开。
- **视觉隐喻**：发现表面不同的东西之间的隐藏相似，本身就让人愉悦。设计里：让题材里的物件承担界面功能（印章即按钮、刻度即进度条），比加装饰更有力。

## 四、构图：平衡、疏密与留白

**依据**

- Arnheim《艺术与视知觉》：画面里每个元素都有视觉重量，取决于大小、明暗、色彩、位置和方向。平衡不是对称，而是各种力相互抵消。
- 统一与变化：太多统一就单调，太多变化就混乱；秩序带来平静，过度的秩序带来无聊。
- 中国画论的"疏可走马，密不通风""计白当黑"讲的是同一件事：疏密要拉开对比，空白本身是画面的一部分。见 `cjk-typography.md` 的"东方画论"一节。

**执行（技巧 6 删完之后做）**

1. **眯眼看**：把截图缩小或模糊，只看明暗块。重量是否偏向一边？视线第一落点是不是最重要的那个元素？
2. **疏密**：区块之间的间距是否处处相同？相同就是模板。让有关联的更紧，转折处更空。
3. **留白有方向**：空白应该把视线引向某处，或衬托某个元素，而不是"每块之间都空一点"。
4. **巧合**：找出所有差几像素就对齐、相切、重叠的地方，逐个改成明确对齐或明确拉开。
5. **统一与变化**：列出全页用到的字号、颜色、圆角、间距的种类数。种类太多就合并，全页只有一种就制造一处对比。
