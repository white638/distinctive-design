# 中文排版与中文字体

设计里只要有中文，就过一遍这份清单。西文排版的经验大多不能直接搬过来。

## 字体选择

- **先确认授权**。可免费商用、适合网页的常见选择：思源黑体 / 思源宋体（Noto Sans SC / Noto Serif SC，OFL）、霞鹜文楷（LXGW WenKai，OFL）、得意黑（Smiley Sans，OFL）、阿里巴巴普惠体、站酷系列（快乐体、高端黑、庆科黄油体等）。方正、汉仪、造字工房等商业字体网页嵌入需要授权，不要直接打包进产品。
- 有性格的中文字体比有性格的西文字体少得多，所以中文的个性更多来自**字号对比、字重对比、宋黑对比、竖排、版心与留白**，而不是靠换字体。
- 正文用宋体要谨慎：屏幕小字号下宋体的细横容易发虚，正文宋体至少 16px，更稳妥的是标题宋体、正文黑体。
- 西文字体放在 `font-family` 的中文字体**前面**，这样西文和数字用西文字体渲染；反过来会用中文字体里通常很平庸的西文字形。
- 系统回退栈：`"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", sans-serif`（宋体回退：`"Songti SC", "STSong", "SimSun", "Noto Serif SC", serif`）。

## 体积

中文字体动辄几 MB 到十几 MB，直接 `@font-face` 整包加载会严重拖慢首屏。

- 标题等固定文字：用 fonttools 按实际用字子集化，再转 WOFF2。
  ```bash
  pip install fonttools brotli
  pyftsubset SourceHanSerifSC-Bold.otf --text-file=used_chars.txt --flavor=woff2 --output-file=title.woff2
  ```
- 正文或用户生成内容：用按 `unicode-range` 切片的服务（如 Google Fonts 的 Noto SC 系列会自动切片），或干脆用系统字体。
- 加 `font-display: swap`，并确认回退字体与目标字体的字面大小接近，避免换字时跳动。

## 排版细节

- **行高**：正文 1.6–1.8，比西文更松；标题 1.2–1.35。
- **字距**：西文标题常用的负字距（`letter-spacing: -0.02em` 一类）不要作用到中文上，会挤成一团。中文正文字距 0 到 0.05em；大标题可以略放开。中西文共用一个样式时，给中文容器单独覆盖。
- **行长**：正文每行约 25–40 个汉字。宽屏上不加限制的中文段落非常难读。
- **对齐**：中文正文可以两端对齐（`text-align: justify`），比西文效果好；但窄栏下注意别出现大空隙。
- **标点**：`text-spacing-trim` 可以压缩连续标点和行首标点的空白。展示型标题可用 `font-feature-settings: "palt"` 收紧标点（字体需支持，如思源系列）。不要在中文后面跟半角标点。大字号标题里全角逗号、句号自带的半格空白会被放大成明显的洞，要么收紧，要么改用断行代替标点。
- **中西文间距**：`text-autospace` 自动在中文与西文、数字之间加空隙。它默认只在原文没有空格时插入，所以文案里已经手动加了空格也不会变成双倍。
- **浏览器支持（截至 2026-10，两者互补，都要写）**：

  | 属性 | 支持 | 不支持 |
  |---|---|---|
  | `text-spacing-trim` | Chrome / Edge 123+ | Safari、Firefox |
  | `text-autospace` | Firefox 145+、Safari 27+（含 iOS） | Chrome、Edge |

  两个属性同时写，各浏览器各取所需；都不支持时页面照常显示，只是少了这层修饰。要求所有浏览器一致的中西文间距时，在文案里手动加空格。
- **强调**：中文字体没有真正的斜体，`font-style: italic` 只会生成难看的伪斜体。强调用字重、颜色，或着重号 `text-emphasis: filled dot`（部分浏览器需 `-webkit-` 前缀）。伪粗体同理，字体缺对应字重时不要让浏览器硬加粗。
- **断行**：避免标题孤字成行（一行只剩一个字），手动用 `<br>` 或调整字号与容器宽度；`text-wrap: balance` 对短标题有帮助。

## 有中文才有的设计手段

- **竖排**：`writing-mode: vertical-rl`；竖排中的两位数字用 `text-combine-upright: all` 横置。适合标题、侧栏、节标题，不适合长正文的网页阅读。
- **版心与天头地脚**：借古籍或书籍版式（栏线、鱼尾、页码、书耳）组织页面，而不是卡片网格。
- **大字号单字或词作为图形**：汉字本身就是很强的图形元素。
- **印章、朱批、批注**：作为点缀和交互反馈。

警惕把"中国风"做成新的套路：水墨晕染、祥云、毛笔字标题、大红配金，和紫色渐变一样是一眼可辨的模板。灵感应该来自具体的物件和传统（某一部刻本、某一类票证、某一家老字号的招牌），而不是笼统的"东方美学"。

## 中文 AI 腔

改文案时删掉或改写：赋能、助力、打造、一站式、全方位、全链路、极致、引领、重新定义、开启……新篇章、让……更简单、不止于……、不是……而是……、在这个……的时代、您的专属……、智慧……（作前缀）、四字词连用、三连排比、破折号和冒号滥用。每个功能写一句"它做什么"就够，不要再补一句"它让你……"。
