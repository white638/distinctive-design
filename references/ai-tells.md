# AI 痕迹清单（截至 2026-10）

用在两个时点：技巧 1 写完方向说明后查"组合套路"，技巧 7 打磨时逐项查三层。**不要在开工时把它当禁令**，那会让模型过度思考、冒出更怪的模式。

AI 的套路随模型更替而移动：第一代是紫色渐变和发光光斑，现在是 bento 网格、毛玻璃和每个标题上的眉标。这份清单注明日期，发现新的高频套路就补进来，过时的删掉。

## 计数规则

> 一个套路是选择，五个就是默认。

单个元素都可以是有意为之：渐变可以符合品牌，居中可以适合只讲一件事的页面。问题出在它们一起出现，因为那说明没有人做过选择。所以不要逐条"有就删"，而是：

1. 截图对照下面三层，数命中了几条。
2. 命中 0–2 条：逐条确认每一条都有出处（来自种子、灵感物件或品牌），没有出处的换掉。
3. 命中 3 条及以上：这一版大概率是默认值。回到 `.design/direction.md`，找出是哪一步被拉回平均值，从那里重新推，而不是逐条打补丁。
4. 命中任何一个"组合套路"：直接按第 3 条处理。

## 第一层：老套路

| 常见 AI 痕迹 | 可尝试的替代 |
|---|---|
| 紫 / 蓝 / 粉渐变背景、渐变文字 | 有出处的配色（来自种子或灵感源），纯色 + 质感，单一强调色 |
| 左文右图的 hero + 两个 CTA 按钮；居中 hero + 三张卡片 + 居中 CTA | 全幅图像、文字压在图像上、非对称或编辑式排版、交互本身当 hero |
| 标题上方的小药丸徽章（"✨ 全新发布""Coming Soon"） | 删掉，或改成有信息量的真实细节 |
| 三列 / 四列等宽功能卡片，各配一个图标 | 内容有几条就排几条，最重要的放大；真实产品截图；一个功能讲深讲透 |
| 所有东西都装进圆角卡片 + 同一种柔和阴影 | 用留白、对齐和字体层级分组；卡片只给能点击或要比较的东西 |
| 玻璃拟态、模糊光斑、发光边框、霓虹外发光 | 真实图像、材质纹理、或干脆什么都不加 |
| emoji 或通用线性图标（Lucide 一类）充当插图 | 定制插画、生成图像、或不用图标 |
| Inter / Manrope / DM Sans / 系统字体通吃 | 有性格的标题字体 + 易读的正文字体，并写进方向说明让后续都用它 |
| "10x 更快 / 99.9% / 10k+ 用户"统计数字条 | 真实数据或删除 |
| 虚构的推荐语和头像墙、"Trusted by"灰色 logo 墙 | 真实评价和真实客户，或删除 |
| 每个元素都在淡入上移的滚动动画 | 少而有意义的动效，服务于叙事 |
| 每张卡片悬停都上浮加阴影；每个按钮里都有一个滑动的小箭头 | 只给可点击的东西反馈，反馈方式与形状语言一致 |
| 页脚四栏链接、末尾 FAQ 手风琴 + 再来一遍 CTA | 只保留真正需要的链接和真有的高频问题 |
| 每段文字都配小标题 + 说明 + 图标；每个列表前都是绿色对勾 | 合并、精简、让图像承担说明；普通列表用普通符号 |
| 三档定价（基础 / 专业"最受欢迎" / 企业），哪怕只有一个价 | 实际卖几档就放几档 |
| 彩色左边框的卡片、提示框、引文 | 顶部细线、底色、字重来区分 |
| 解说性小字：每个模块配一句抒情旁白或自我说明，预先写好的错误提示，告诉用户实现细节的说明，重复的元信息 | 按 SKILL.md 技巧 8 的小字审计逐条删，留下的说得出删了会损失什么 |

## 第二层："为了显得独特"的新套路

模型被要求"别像 AI"时，会滑向第二个平均值。下面每一项单独用都没错，但都是被要求"有设计感"时最先冒出来的选择：

| 新套路 | 检查方式 |
|---|---|
| 标题里一个词换成衬线斜体，或换成强调色（"Build *beautiful* things"） | 大声读标题，那个词是否真的是重音；不是就整句统一 |
| 每个区块上方的小号全大写眉标，或 `[ 01 ]` 式等宽编号 | 删掉眉标，标题是否依然清楚；编号是否表达了真实顺序 |
| Bento 网格（大小不一的圆角格子拼满一屏） | 格子大小是否对应内容的重要性；内容是递进关系就写成序列 |
| 全屏颗粒 / 噪点、渐隐的点阵背景 | 质感是否服务于灵感来源，还是为了"不那么数字" |
| 假手写：马克笔箭头、圈注、"psst!" | 删掉后按钮是否变弱；变弱说明该改的是旁边的文案 |
| 非开发者网站上的终端窗口（红黄绿三点 + 命令行） | 产品是否真的与命令行有关 |
| 强调色铺满链接、图标、标题词和所有按钮 | 强调色只留给最想让人点的那一处 |
| 所有元素同一个 16px / 24px 圆角，或全部胶囊按钮 | 圆角像配色一样要有决定：全直角显得精确，只给可点击物圆角能教会用户哪里能点 |
| 超大居中标题 + 一行灰色副标题 + 一个按钮，此外空无一物 | 空是因为克制，还是因为没东西可放 |
| 标题用 Fraunces、Instrument Serif、Playfair Display、Cormorant、Space Grotesk、Geist、Outfit | 这些"有性格"的字体用在标题上已经成了标志；用在正文或界面文字上仍可以 |
| 标题字距压到 -0.04em 以下 | 存在感靠字号和字重，不靠挤压 |
| 水墨、祥云、毛笔字、红金配色（"中国风"） | 见 `cjk-typography.md` 末节 |
| 写实照片般的脸、身体往下化成墨晕或水彩的人像（AI 水墨肖像） | 换一个具体画家或技法的笔墨语言（减笔、白描、版画），让整幅画用同一种手法画出，而不是照片加滤镜 |
| 名人最出名的那句话做成深色通栏引语条（"Be water, my friend."） | 这句话是否非放不可；要放，就让它进入版式或交互，而不是单独一条深色带 |
| 左上全大写加宽字距的英文名眉标 + 侧边竖排生卒年 | 删掉后是否损失信息；年份放进真正讲年代的地方 |
| 吸管平涂：从主视觉吸一个颜色铺满全页 | 背景是否有渐变、材质、光和第二个色相；见 `aesthetics.md` 第五节 |
| 换图加蒙版：被说单调后换一张无关的全幅照片，再盖统一深色蒙版 | 照片是否属于主视觉的世界；蒙版是否只压在文字下面 |
| 深色照片上的纯白实色卡片、铺满整行的浅色选中条 | 表面是否从环境取色；能否去掉或改成半透明；见 `aesthetics.md` 第六节 |

## 第三层：组合套路

每个元素都能通过上面两层的检查，但组合在一起，不管什么题材都会长成同一个样子。命中任何一个，都要回到方向说明重新推：

| 组合 | 构成 | 出路 |
|---|---|---|
| 暖色编辑风（warm editorial） | 奶油 / 米白底（约 `#F4F1EA`）+ 高对比衬线或宋体标题 + 赤陶橙（约 `#D97757`）或墨绿强调色，常配一张全宽风景照 | 保留"衬线 + 中性色"的结构也可以，但底色和强调色必须离开奶油—赤陶 / 墨绿这一对，并能指出出处 |
| 酸性暗色（acid dark） | 近黑底 + 恰好一个酸绿或朱红强调色 | 仍可"中性色 + 一个强调色"，但色相从题材本身取 |
| 报纸版（broadsheet） | 细线分隔 + 零圆角 + 报纸式密排多栏 | 保留密度，但改变线的粗细、圆角或栏的节奏，别让三者同时出现 |
| 暗色精致风 | 深色底 + Fraunces 类软衬线斜体点题 + 其余全用 Inter + 琥珀或暗紫一点色 + 角落有等宽标签的卡片网格 | 同上，回到抽签结果找配色和字体的出处 |
| 人物专题套件 | 左侧超大标题 + 右侧人物大图的首屏 + 带圆点的时间轴 + 深色引语条 + 手风琴作品列表 + "继续阅读" + 灰色小字页脚 | 结构可以是线性阅读，但每段的形态从题材里长出来：武打明星的生平可以是分镜或动作分解，作品可以是片头或海报墙，而不是通用组件 |
| SaaS 卡片套件 | 处处同样的圆角卡片、同一个圆角半径、同一种浅灰阴影、渐变底纹作装饰 | 按层级给卡片不同处理，去掉共享的圆角 / 阴影 / 渐变组合 |

如果 brief 或品牌明确要求其中某种风格，照 brief 做。这份清单反对的是"没人选过的默认值"，不反对任何一种风格本身。

## 情绪默认值

套路不只出现在视觉上，也出现在"想要的感觉"里。下面这些词能用在几乎任何题材上，写进方向说明时要格外警惕：

- 沉静、克制、留白、高级、质感
- 温暖、治愈、松弛、慢
- 庄重、纪念、致敬、传承
- 未来感、科技感、极致

**替换测试**：把题材换成同类里的另一个人、另一件产品，这句感觉是否依然成立？成立就是默认值。回到题材最有辨识度的特征去推：以速度和爆发力著称的武打明星，感觉从"快、骤然、一触即发"出发；以絮叨和幽默著称的作家，感觉从"跑题、俏皮"出发。

评审读出的情绪与目标一致，只能说明目标传达到了，不能说明目标本身选得对。
